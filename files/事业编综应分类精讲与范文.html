综合应用能力五类试卷题型不同、评分逻辑相通：要点全、结构清、语言实。本资料每类给一道典型题的完整作答示范，照着结构练，就能拿分。

一、A类（综合管理）

常考题型

  • 归纳概括、观点分析、校阅改错、论证评价、材料分析、公文写作（管理岗卷面常见组合）；
  • 核心能力：从材料里「找全要点、分好类、说清楚」。

典型题示范：应急处理题

题目（自拟示例）：你是街道办工作人员，多位居民投诉小区垃圾分类点撤桶并点后投放距离远、乱扔垃圾增多。请提出处理思路。

参考作答框架：

  1. 稳住局面：第一时间回应居民，公布处理时限，防止情绪升级；
  2. 查明原因：实地查看投放点分布、清运频次，走访居民听取意见；
  3. 分类施策：对行动不便群体增设误时投放点或安排上门收集；对乱扔行为加强劝导与曝光；对清运不及时协调物业增派车辆；
  4. 长效跟进：公示整改方案，一周后回访满意度，把「撤桶并点」的环保意义讲透，争取居民理解。

得分要点：先回应再处理（态度分）→ 调查在前施策在后（逻辑分）→ 措施具体可落地（内容分）→ 有回访有闭环（完整分）。

应急处理题万能框架

稳情绪 → 查实情 → 分轻重 → 提对策 → 防再发。记住：任何应急题都先「人」后「事」，先止损再追因。

二、B类（社科专技）

常考题型

  • 概念（定义判断型主观题）、校阅改错、论证评价、材料分析、作文；
  • 核心能力：逻辑严谨、表述准确。

概念题技巧

  • 答题公式：属＋种差——先说「它属于哪一类」，再说「它区别于同类的关键特征」；
  • 材料中找定义的「三要素」：主体、行为方式、目的/结果，缺一不可地抄进答案；
  • 常见失分：只抄例子不提炼、要素遗漏、用自己的口语替换材料关键词。

校阅改错技巧

  • 错误类型就五种：错别字、语序不当、搭配不当、成分残缺或赘余、逻辑矛盾；
  • 逐句读，先找「搭配」和「逻辑」这两类高频错误；改正时「最小改动」原则，别整句重写。

三、C类（自然科技）

常考题型

  • 科技文献阅读、实验设计、论证评价、材料作文；
  • 核心能力：读懂数据、识别论证漏洞。

论证评价题技巧

  • 常见论证漏洞四类：偷换概念（前后概念不一致）、以偏概全（样本推总体）、强加因果（相关当因果）、论据不足（缺对照组/缺数据）；
  • 答题模板：「文中由……推出……，该论证存在……的缺陷，因为……，正确结论应为……」；
  • 每条漏洞独立成段，先指错再说理，不要笼统说「论证不严谨」。

实验设计题要点

  • 三要素：对照组设置、变量控制、样本代表性；
  • 答题时先说「实验目的」，再列「分组—处理—观测指标—结论」四步。

四、D类（中小学教师）

常考题型

  • 教育情境题（辨析+案例分析）、教案设计、教育作文；
  • 核心能力：用教育学、心理学原理分析真实课堂问题。

情境题套路

  • 答题三步：亮观点（该做法对不对/怎么办）→ 引理论（对应的教育学心理学原理，如因材施教、最近发展区、正强化）→ 给做法（具体到课堂操作层面）；
  • 常见主题：课堂纪律、学习动机、家校沟通、后进生转化——每个主题背一个理论锚点；
  • 忌空谈「关爱学生」，要写「具体怎么做」。

五、E类（医疗卫生）

常考题型

  • 医学基础知识单选多选、案例分析（临床/护理/公卫等岗位方向）、实务题；
  • 核心能力：基础医学概念扎实＋临床思维清晰。

案例分析题套路

  • 答题四步：初步判断（最可能的诊断/问题）→ 依据（病史、症状、体征中的关键信息）→ 处理原则（急救优先、转诊指征）→ 人文沟通（告知、安抚、随访）；
  • 公卫方向重点：传染病报告制度、流行病学调查基本步骤（核实诊断→个案调查→密切接触者管理→疫点处理）；
  • 护理方向重点：护理评估—诊断—计划—实施—评价的程序化表达。

六、五类通用得分心法

原则怎么做
要点全按材料顺序逐段找点，宁多勿漏，分条呈现
结构清总起一句＋分条展开；每条「观点＋简析」
语言实用材料关键词，不用口语；不写空话套话
卷面净分条编号、段落分明，字迹工整值 2~3 分
亿成老师提醒：综应不是「写得多就得分」，阅卷踩点给分。练题时先自己写，再对照「得分要点」逐条勾，缺哪补哪，五套题下来结构感就有了。
