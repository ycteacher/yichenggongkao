亿成公考 · 安装指引

把刷题应用装到桌面，像 App 一样一点就开

先说清楚：不装也能用——直接用浏览器打开网址就能刷题。装到桌面只是为了下次一点即开、全屏无地址栏，体验和 App 一样。资料在"资料领取专区"里点保存即可下载。
📺 视频讲解动画一步一步演示 · 跟着点就行 🖼 图片讲解每一步都有大图和说明

手机

iPhone / 安卓
1
用浏览器打开应用网址
iPhone 用 Safari，安卓用 Chrome
2
iPhone：点底部分享图标 → 添加到主屏幕
3
安卓：点右上⋮ → 添加到主屏幕 / 安装应用
4
桌面出现「亿成公考」图标，点开即用 ✅
⚠️ 微信里打开的话，先点右上「···」→「在浏览器中打开」，再按上面步骤操作。

平板

iPad / 安卓平板
1
用自带浏览器打开应用网址
iPad 用 Safari
2
iPad：点顶部分享 → 添加到主屏幕
3
安卓平板：右上⋮ → 添加到主屏幕
4
横屏竖屏都能用，刷题更舒服 ✅
资料下载：点保存后如果打开了预览，再点「分享 → 存储到文件」即可存到平板。

电脑

Windows / Mac
1
用 Chrome / Edge 打开应用网址
2
点地址栏右侧安装图标
或用菜单 →「安装此站点为应用」
3
确认安装，桌面/开始菜单出现图标
4
独立窗口打开，刷题、看数据更清爽 ✅
资料下载：点「保存」会直接下载到「下载」文件夹；点「打开」可在线预览。
