统计口径说明

访问与活跃

  • UV / 独立设备：按匿名设备编号去重，是「独立设备（近似人数）」，不等于真实人数。
  • 实时在线：近5分钟有心跳的设备。
  • 会话：同一设备超过30分钟无心跳后再次出现，算一次新会话。
  • PV：页面打开次数（心跳上报累计）。
  • 今日打开次数：今日会话数，来自学生端新埋点（上线后逐步积累）。

库存积累

  • 历史键：看板每天首次打开时，把昨日终值（日PV / 日活跃设备 / 日播放 / 累计库存）写入 ycgk-hist-<昨日日期>（读-合并-写），看板是唯一写入方。
  • 环比：今日指标与昨日历史键对比；无历史数据时不显示箭头。

视频

  • 正在看视频（实时）：近5分钟内处于观看视频状态的设备数，与「实时在线」同口径，必然 ≤ 实时在线。
  • 播放次数：点「开始播放」计1次；一个视频分多段播放算1次。
  • 播放人数：按匿名设备编号去重，是上线以来累计看过视频的设备数，不是实时值。
  • 完播率：完整看完 ÷ 开始播放。
  • 退出节点：新埋点按 开头30秒 / 中段 / 结尾 三档；历史数据按已看进度四档（<25% / 25–50% / 50–75% / 75–100%）。
  • 难点考点信号：同一设备对同一视频播放 ≥3 次。

设备与安装

  • 安装：PWA beforeinstallprompt 接受 + appinstalled 事件。
  • 安装转化率：今日安装 ÷ 今日独立设备。
  • 品牌 / 网络 / 分辨率：UA 画像新埋点，上线后逐步积累。

稳定性与学习行为

  • 报错：window.onerror + unhandledrejection，消息截断120字符。
  • 加载耗时：loadEventEnd − navigationStart，看 P50 / P90。
  • 学习行为：学生端每60分钟聚合上报答题数据；模块错误率>90% 或正确率>99% 标红，疑似坏题。

问卷

  • 好评率：第1题选「非常好」或「还不错」的比例。
  • 推荐率（NPS近似）：第10题选「肯定会」的比例；选项无贬损项，仅作近似。

暂不支持

  • 精确地域：无IP归属库。真实用户数：一切按设备口径。跳出率 / 人均访问时长：无时长上报。同比：历史数据不足一年。问卷回收率：未记录邀请曝光。视频终端拆分 / 回访播放率：视频端未上报对应字段。

对账入口（原始数据）

  • 实时池：textdb.dev/api/data/ycgk-live-v1
  • 视频池：textdb.dev/api/data/ycgk-vid-v1
  • 问卷池：textdb.dev/api/data/ycgk-fb-v1
  • 学习统计池：textdb.dev/api/data/ycgk-stat
  • 历史库存键：ycgk-hist-YYYYMMDD（如 ycgk-hist-20261122，看板每日首次打开写入昨日终值）
  • 静态快照：metrics-7f3k9q2m.json
